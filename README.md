# CS 405 — Secure Coding Portfolio

## Overview

This repository contains my coursework and projects from CS 405: Secure Coding at Southern New Hampshire University (SNHU). Throughout this course, I learned how to identify security vulnerabilities, follow secure coding standards, and implement practices that help protect software from attacks.

## Projects

### Project One — Security Policy
Developed a security policy for Green Pace that includes 10 security principles, coding standards, and risk assessments to help prevent common vulnerabilities.

### Project Two — Security Policy Presentation
Created a presentation explaining Green Pace's security policies, including defense in depth, encryption, authentication, authorization, security automation, and unit testing.

**[Watch my Project Two presentation on YouTube](https://youtu.be/hhkW_C9tU_8)**

### Coding Activities
- **Numeric Overflow:** Implemented checks to detect and prevent numeric overflow and underflow.
- **SQL Injection:** Added validation to identify and reject suspicious SQL queries.
- **Buffer Overflow:** Improved input handling to prevent oversized input from exceeding buffer limits.
- **Exceptions:** Practiced secure exception handling using standard and custom exceptions.
- **Unit Testing:** Created four C++ unit tests in Visual Studio to verify normal calculations and overflow/underflow detection.

### Portfolio Reflection
Reflected on the importance of secure coding standards, risk assessment, zero trust, and implementing security policies throughout software development.

## Key Takeaways

This course helped me understand that software security should be considered throughout development instead of being added at the end. I learned how small coding mistakes can create vulnerabilities and how secure coding standards, testing, and risk assessments can help prevent them.

These projects demonstrate my understanding of secure software development and the importance of protecting applications and user information.
